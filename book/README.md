# Quantum Fluids in Lean 4: a tribute to Henri Godfrin

A textbook (first edition, October 2026, 282 pages) that teaches quantum-fluid physics through three instruments used
together: the neutron-scattering measurements of Henri Godfrin and his collaborators, the Lean 4 library
`QuantumFluids` of this repository, and the rusty-SUNDIALS solver (CVODE and the projected Gross–Pitaevskii engine
`qf-pgpe`). Henri Godfrin has not reviewed the book, and nothing in it speaks for him or for his collaborators.

**Cite:** X. Callens, *Quantum Fluids in Lean 4: a tribute to Henri Godfrin*, SocrateAI Research (2026),
doi:[10.5281/zenodo.23272153](https://doi.org/10.5281/zenodo.23272153) (concept DOI, always the latest edition).

## Layout

| path | what |
|---|---|
| `quantum_fluids_book.tex`, `quantum_fluids_book.pdf` | the master file and the book |
| `chapters/ch01.tex` … `ch10.tex` | the ten chapters; `appA.tex` (complete catalogue of the Lean library, generated by `facts/make_appA.py`), `appB.tex` (reproducibility) |
| `qfbook.sty`, `figstyle.py` | house style of the text and of the figures; `qf_unicode_lst.tex` and `lean_ns.tex` are generated by `facts/make_appA.py` |
| `figures/chNN_*.py` | every figure script, with its PDF and `chNN_numbers.json` (the source of every computed number in the text) |
| `lean/ChNN_*.lean` | Lean files written for the book (standard axioms only); files named `*NegativeControl*` are meant to fail |
| `rust/` | the small Rust crates of Chapter 8 |
| `facts/` | `FACTS.md` (the authors' briefing, with the editor's dated corrections), `chNN_report.md` (what each chapter verified and where every number comes from), the Lean audit (`lean_audit.md`, `audit/`), the library index, the citation check |
| `refs*.bib`, `build_refs.py` | bibliographies; `build_refs.py` merges them into `refs_all.bib` |
| `make_source_archive.py` | packs the sources deposited with the book |

## Build

LuaLaTeX with EB Garamond, TeX Gyre Pagella Math and DejaVu Sans Mono:

```
cd book
python3 build_refs.py
lualatex quantum_fluids_book && bibtex quantum_fluids_book && lualatex quantum_fluids_book && lualatex quantum_fluids_book
```

How to rebuild every figure, which solver build to use (rusty-SUNDIALS commit 5db8041, not the module of the shared
virtual environment) and how to rerun the Lean audit: Appendix B.

## How the book was made

The chapters were written separately from the same briefing (`facts/FACTS.md`) and combined by the editor; text,
Lean code and figures were drafted with the assistance of an AI system and then checked: the Lean files compile against
the pinned Mathlib, the solver code was run, every Lean excerpt was compared with its source by a script
(`facts/appA_citation_check.md`), and the sources of every number are listed in the per-chapter reports.
Corrections are welcome.
