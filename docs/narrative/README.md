# Narrative & Speculation (Tier C — Non-Peer-Reviewed)

**⚠️ WARNING: Content in this directory is exploratory and not subject to the program's citation-verification or unit-test standards.**

---

## Policy

This directory contains speculation, hypotheses, and narrative explorations that are:

1. **Not Tier-A** (no citation requirement)
2. **Not Tier-B** (no unit tests)
3. **Clearly marked** as non-peer-reviewed
4. **Isolated** from the main claim ledger (LEDGER.md)

Examples:
- Interpretations of dark-matter bridge beyond named experimental programmes (Hirschel et al. 2024, etc.)
- Philosophical or cosmological speculation around quantum fluids
- Exploratory analogies between quantum fluids and other systems (if not grounded in literature)

---

## Entry structure

Each file should have a banner at the top:

```markdown
# [Title]

**STATUS: EXPLORATION / SPECULATION**  
**TIER: C (Non-peer-reviewed narrative)**  
**Date:** 2026-08-14

⚠️ **This is not subject to citation-verification or unit-test requirements.**

[Content here]
```

## Engagement policy

Narratives do not receive email engagement. Inquiries should be directed to:
- The main SocrateAI issue tracker
- The project coordinator (see README.md)
- NOT to replies on this narrative section

---

## Cross-reference

If a narrative piece matures into a testable claim, it should be:
1. Migrated to the main docs/ directory (or EXPRESSION_MEMO_E1.md)
2. Given a LITERATURE_LEDGER.md entry (Tier A)
3. Given unit tests (Tier B)
4. Filed in LEDGER.md with appropriate status

The narrative file remains as historical record, but the claim moves to the verified section.
